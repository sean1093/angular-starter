# angular-starter

A self-learning notes for Angular 4

> [!WARNING]
> **本筆記寫於 2017–2018 年，內容基於 Angular 4（Angular CLI 1.4、TypeScript 2.3、RxJS 5），目前已不再維護。**
> 現在的 Angular 有許多不相容的改變，照著這份筆記操作可能無法執行，請以 [Angular 官方文件](https://angular.dev) 為準。主要差異例如：
>
> * `@angular/http`（`Http`）已移除，請改用 `@angular/common/http` 的 `HttpClient`
> * RxJS 的 `import 'rxjs/add/operator/...'` patch 寫法已移除
> * 新專案預設使用 standalone component，不再需要 `NgModule`
> * 樣板可使用 `@if` / `@for` 等內建控制流程，取代 `*ngIf` / `*ngFor`
> * `sample-app` 使用的 TSLint、Protractor、PrimeNG 4 `DataTable` 等工具與元件皆已停止維護或移除
